# Getting started with bayan

## Build

```sh
cyrius deps                              # resolve dependencies
cyrius build src/main.cyr build/bayan    # compile
cyrius test                              # run [build].test + tests/*.tcyr
```

## Layout

- `src/main.cyr` — entry point. Top-level `var r = main(); syscall(SYS_EXIT, r);`.
- `src/test.cyr` — top-level test entry referenced by `cyrius.cyml [build].test`. Add unit cases here or in `tests/bayan.tcyr`.
- `tests/bayan.tcyr` — primary test suite (`cyrius test` auto-discovers).
- `tests/pdf_flate.tcyr` — the PDF compression path, kept in its own binary
  because it is the only test that pulls in `lib/sankoch.cyr`.
- `tests/pdf_fixture.cyr` — writes a PDF for CI to run through the strict
  validator at `scripts/pdfcheck.py`.
- `tests/bayan.bcyr` — benchmarks (`cyrius bench`), results in
  [`../benchmarks.md`](../benchmarks.md).
- `tests/bayan.fcyr` — fuzz harness (`cyrius fuzz`), which drives the PDF
  reader over the fixture corpus truncated and byte-flipped.
- `tests/fixtures/pdf/` — eleven PDFs, generated by
  `scripts/gen-pdf-fixtures.py`. `ref-*` must parse; `bad-*` must be refused.

## Adding a feature

1. Edit `src/main.cyr` (or add a new module and `include` it).
2. Add a test case to `tests/bayan.tcyr`.
3. Run `cyrius test`.
4. Bump `VERSION` and add a CHANGELOG entry before tagging.

## Writing a PDF

[`../examples/pdf_report.cyr`](../examples/pdf_report.cyr) is a runnable
example: it builds a paginated two-page report with wrapped body copy, then
reads the file back and extracts its text.

```sh
cyrius build docs/examples/pdf_report.cyr build/pdf-report
./build/pdf-report /tmp/report.pdf
python3 scripts/pdfcheck.py /tmp/report.pdf --text
```

Two things to know before you start:

- **All geometry is in milli-points.** 1 pt = 1000 mpt, so A4 is
  595000 x 842000. There is no floating point in the module — PDF reals have no
  exponent form, so a float formatter cannot be used safely.
- **Compression is opt-in.** `bayan_pdf_*` has no dependency on
  `lib/sankoch.cyr`; install the hooks yourself if you want Flate. See the
  README, and [ADR-0001](../adr/0001-flate-via-hooks-not-a-sankoch-dependency.md)
  for why it works this way.

`scripts/check-widths.py` verifies the checked-in font metrics using nothing
but the Python stdlib, and is what CI gates on. `scripts/gen-widths.py`
*regenerates* them from groff's Adobe metrics and is only needed when the
tables actually change — install groff for that.

`scripts/pdfcheck.py` is the acceptance oracle and is deliberately stricter
than a viewer: it validates every cross-reference offset against the byte it
claims to point at, where poppler and mupdf would silently rebuild a broken
table. Run it on anything you generate.

See [`../adr/template.md`](../adr/template.md) when a non-trivial design choice deserves an ADR.
